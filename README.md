# FolderSorter - 文件夹分类助手

**中文** | [English](README.en.md)

---

## 简介

FolderSorter 是一个用于 Windows 的简易文件夹分类助手。

它可以帮助用户快速整理大量文件夹，逐个查看内容，并将整个文件夹移动到指定位置。

## 功能

- 快速浏览并整理大量文件夹
- 将整个文件夹移动到指定位置，而不是单个文件
- 自动进入下一个文件夹，提高整理效率
- 跳过当前文件夹，不进行任何操作

## 说明

- 本软件目前仅提供中文界面。
- 软件不会自动判断文件夹分类，用户需要手动判断文件夹归属，并选择目标位置进行整理。
- 移动操作针对整个文件夹，而不是其中的单个文件。
- 本项目在 AI 辅助下完成，作者并非专业软件开发者。
- 本项目最初用于解决个人文件整理需求，目前功能已满足个人使用需求，因此暂时没有持续开发计划。
