## About

FolderSorter is a simple Windows tool for organizing folders.

It helps users organize a large number of folders by reviewing them one by one and moving folders to selected locations.

## Features

- Review and organize a large number of folders
- Move entire folders to selected locations instead of individual files
- Automatically proceed to the next folder to improve efficiency
- Skip the current folder without any operation

## Notes

- The software currently only supports Chinese.
- The software does not automatically categorize folders. Users need to decide where each folder belongs and select the destination manually.
- Moving operations apply to entire folders, not individual files inside them.
- This project was developed with the help of AI. The author is not a professional software developer.
- This project was originally created to solve a personal file organization problem. The current features meet the original needs, so there are no plans for continuous development at the moment.
